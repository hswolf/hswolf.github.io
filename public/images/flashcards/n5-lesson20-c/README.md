# Images for N5 Bài 20 - Phần C flashcards

Drop image files named `1.webp` … `19.webp` into this directory. The card component will pick them up automatically. Missing files are silently hidden — no broken-image icons.

**Recommended specs**
- Format: WebP (smaller) or PNG/JPG (edit `image:` field in the deck data if you use a different extension)
- Size: 512×512 or 1024×1024 square, under ~150 KB each
- Style: keep it visually consistent across the deck so the UI feels cohesive

**Style suggestion for a matching zen aesthetic**

Prepend every prompt with:

> _Soft minimalist illustration on a warm cream/beige background (#F5F0EB), muted earth-tone palette, gentle shadows, no text or words in the image, square composition, suitable as a flashcard thumbnail._
